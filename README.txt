ONE STOP CENTRE INTERAKTIF - UNIT BIMBINGAN DAN KAUNSELING SMK BULUH KASAP

CARA GUNA
1. Buka index.html.
2. Gunakan menu kiri untuk memilih modul.
3. Semua modul dibuka dalam portal yang sama.
4. Butang “Buka Penuh” membuka modul semasa dalam tab baharu.

UNTUK NETLIFY
- Drag & drop KESELURUHAN folder OSC_INTERAKTIF_SMKBK ke Netlify Drop,
  atau muat naik fail ZIP ini selepas diekstrak.
- Pastikan struktur folder `pages/` dikekalkan.

UNTUK GITHUB PAGES
- Muat naik semua kandungan folder ini ke root repository.
- Pastikan index.html berada di root.
- Aktifkan GitHub Pages untuk branch yang digunakan.

NOTA
- Sesetengah modul mempunyai pautan ke Google Drive / Telegram dan memerlukan internet.
- Kandungan halaman asal dikekalkan; portal baharu berfungsi sebagai satu shell navigasi bersepadu.
